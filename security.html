Security Model

The questionnaires and scoring run in your browser.

  • Site files The browser downloads code, questionnaires and PDF tools from this site.
  • Answers The app keeps answers in memory and uses no account or database.
  • Shared devices Close the tab when finished and check the downloads folder for saved reports.
