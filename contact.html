Contact & Disclosure

This site intentionally hosts no contact forms (forms would imply a backend that does not exist). Reach us through these out-of-band channels instead.

  • Repository issues For bugs, feature requests, and clinical-content corrections, open an issue in the project's public source repository. Every fix is reviewed as a version-controlled change.
  • Vulnerability disclosure Report security issues privately via the repository's security advisory channel. Please do not file them as public issues until a patch is available.
  • Clinical questions Scale selection, scoring bands, and differential mappings are documented in WHITEPAPER.md. Clinicians reviewing patient-exported PDFs should treat results as intake context only, never as diagnoses.
  • Not an emergency channel EPCSS staff cannot monitor any inbox in real time and this tool cannot call services for you. If you are in immediate danger or crisis, contact your local emergency number or a crisis helpline right now — the screening app lists localized options when safety items are endorsed.
  • Data requests There are none to fulfill: no user data is collected, transmitted, or stored anywhere by this application.
In crisis? Use the helplines shown inside the screening flow, or your country's emergency services. Do not wait for an email reply.
