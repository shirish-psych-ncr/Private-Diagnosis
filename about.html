About EPCSS

EPCSS — Ephemeral Pre-Consultation Clinical Screening — is a zero-backend, zero-persistence intake aid that prepares structured information for a clinician before an appointment.

  • What it is A static web application that walks you through consent, context, symptom domains, and validated clinical scales (PHQ-9, GAD-7, PCL-5, and others), then produces a summary you can export as a PDF for your clinician.
  • What it is not It is not a diagnostic instrument. It never returns a diagnosis and does not replace clinical judgment.
  • Ephemerality All answers live only in this browser tab's volatile memory. Closing the tab permanently destroys them. There is no server, no database, and no analytics.
  • Safety override If a response indicates possible distress or crisis, the app immediately surfaces localized crisis resources in a modal that cannot be bypassed silently.
  • Bilingual by design The full screening experience is available in English and हिंदी, and the language can be switched at any point without losing answers.
  • Open clinical logic Scoring rules, domains, instruments, and the disorder reference database are maintained in a single human-readable data file subject to version-control audit.
  • For clinicians The exported report includes scores, banding, and differential considerations formatted for professional review, kept behind an explicit toggle.
  • Technology Vanilla HTML, CSS, and JavaScript with strict Content Security Policy. No frameworks, no trackers, no third-party fonts.
